Personal Utility Dashboard
C# Console Application · Beginner level

This will be a program consisting of four main modules: a user profile, a budget calculator, a mathematical calculator, and a text analyzer.
Practical Project
C# Fundamentals

2. Your Task
Part A — Personal Profile
Create a user profile.

The program must ask the user for the following:
Information	Variable	Type
Name	name	string
Age	age	int
City	city	string
Group letter	groupLetter	char
Is a full-time student? isFullTime	bool
Favorite technology	favoriteTechnology	string

Requirements:

Use Console.ReadLine() and the appropriate Convert methods to obtain the information.

Then, display the profile in the console.

Use .ToUpper() for the title and string interpolation ($"...") to output the values. Part B — Budget Calculator
Now you will create a simple monthly budget calculator.

Ask the user for the following:
Information	Variable	Type
Monthly budget	monthlyBudget	decimal
Regular expenses	regularExpenses	decimal
Extra expenses	extraExpenses	decimal

Then, calculate:
1. Total expenses (totalExpenses).
2. Remaining budget (remainingBudget).
3. The updated budget after increasing the monthly budget by 100 BGN.
Requirements:

Use `+=` to add the extra expenses, and either `+=` or `+` to increase the budget.

Also, create a boolean variable named `isBudgetEnough` that checks whether the monthly budget is greater than or equal to the total expenses.

This exercise will help you practice using the `decimal` type, as well as assignment and comparison operators.
Part C — Advanced Calculator
This is the mathematical module.

Ask the user for two numbers:
double firstNumber;
double secondNumber;


Then, perform the following calculations:
Operation	Action required
Sum	Add the two numbers
Difference	Subtract the second number from the first
Product	Multiply the two numbers
Division	Divide the first number by the second
Remainder	Find the remainder of the division

Also, use comparison operators to determine:
- Is the first number greater than the second?
- Are the two numbers equal?
- Is the first number less than or equal to the second?
Store the results in `bool` variables.

Finally, create another boolean variable that checks whether the user is of legal age (an adult) AND a full-time student, using the `&&` operator. Additional Exercise: Type Casting

Convert the first number from `double` to `int` using `(int)` and output the result.

Remember: for division and the modulo (remainder) operation, the second number must not be zero. For now, we will avoid using zero during testing, as we haven't covered `if` statements yet.
Part D — Math Operations
Next, we will work with the built-in `Math` class.

Using the first number from the calculator, output the following:
- Square root using `Math.Sqrt()`.
- Absolute value using `Math.Abs()`.
- Rounded value using `Math.Round()`.
- Rounded up (ceiling) using `Math.Ceiling()`.
- Rounded down (floor) using `Math.Floor()`.
- Squared (raised to the power of 2) using `Math.Pow()`.
Then, using both numbers, determine:
- The larger number using `Math.Max()`.
- The smaller number using `Math.Min()`.
For the square root, ensure you use a non-negative value—for example, the absolute value of the first number.
Additional Task — Circle Calculator
Ask the user for the radius of a circle, then calculate its area and circumference.

Use `Math.PI` and `Math.Pow()`.

This is a great opportunity to practice the formulas from the previous exercise once more.
Part E — Text Analyzer
The final module involves analyzing text entered by the user.

Request the following input:
Information	Variable	Type
Sentence	`sentence`	`string`
Search word	`searchWord`	`string`
Replacement word	`replacementWord`	`string`

Then, perform the following operations:

1. Text Transformation
- Output the sentence in uppercase letters. - Output the sentence in lowercase.
2. Text verification
- Output the length of the sentence using `Length`.
- Check if it contains the search term using `Contains()`.
3. Text editing
- Remove extra spaces using `Trim()`.
- Replace the search term with the new one using `Replace()`.
4. Text analysis
- Find the position of the word using `IndexOf()`.
- Output the first 4 characters using `Substring()`.
- Check if the sentence starts with the letter 'I' using `StartsWith()`.
- Check if it ends with a period using `EndsWith()`.
For the `Substring()` exercise, the entered sentence must contain at least 4 characters.
